# 功能清单

> 心跳轮询已移除（看门 + 独立大脑足以覆盖其职责）。本清单按「能配置 / 不能配置」划分。
> 所有配置修改仅限管理员（`admin.qq` / `admin.wechat` 名单），经 `set_config(点分路径, 值)` 修改。

## 消息处理模式（二选一，互斥）

| 模式 | 启动方式 | 特点 |
|---|---|---|
| 事件驱动看门 | `python server/inbox_watch.py`（ZCode 后台任务或常驻） | 消息到达即醒（延迟≈1 秒），零模型成本；日班期间与大脑换班长睡 |
| 独立大脑 | `python server/persona_mcp.py --brain` | 秒级轮询 + 规则预筛 + LLM 人格回复 + 实时沉淀 + 主动搭话 |

## ✅ 能配置的

### 渠道
| 配置键 | 作用 | 默认 |
|---|---|---|
| `qq.enabled` | QQ 渠道开关 | false |
| `qq.napcat_base_url` | NapCat OneBot 地址 | http://127.0.0.1:3000 |
| `qq.napcat_token` | NapCat access token | 空 |
| `qq.webui_url` / `qq.webui_token` | NapCat WebUI（掉线自动快速登录用） | 6099 / 空 |
| `qq.napcat_path` | NapCat.Shell 框架目录（自动发现/拉起用） | 空（自动发现） |
| `qq.autostart` | collector 启动时自动拉起 NapCat | false |
| QQ 凭据 | 经 `save_qq_credentials` 托管（DPAPI 加密），非 set_config | 未托管 |
| `wechat.enabled` | 微信渠道开关 | false |
| `wechat.adb_path` / `wechat.device_serial` | ADB 路径 / 设备序列号 | adb / 自动检测 |
| `wechat.input_tap_x` / `wechat.input_tap_y` | 微信表情包面板校准坐标 | 0 |
| `wechat.human_trace` | ADB 滑动轨迹随机化 | true |
| `video.ffmpeg_path` | ffmpeg 路径（视频抽帧） | ffmpeg |

| 配置键 | 作用 | 默认 |
|---|---|---|

### 经工具配置（非 set_config）
人格库增删改与热切换（`manage_persona`）、黑白名单三种粒度（`manage_rules`）、表情包库增删（`manage_stickers`，带 source_url 自动去重）、账号关联发起/确认/消解（`link_accounts`）、记忆清理（`prune_memory`，先 dry_run）。

## ❌ 不能配置的（内置固定行为）

- **消息处理模式仅两种**（看门/独立大脑）且互斥；心跳定时轮询已移除。
- **双渠道协议**：QQ=NapCat OneBot 11；微信=ADB；collector 兼容 chunked 上报、端口被占自动复用单例。
- **值班交接语义**：大脑开工跳过开工时刻前创建的消息（归夜班），防双脑重复回复。
- **内容防火墙**：恶意内容在 collector 层拦截，原文永不进大脑（仅元数据可审查）；拦截计数联动守卫。
- **出站泄密反向扫描**：发送文本含已托管密钥值直接拦截；托管密码任何接口不回显。
- **管理守卫**：非管理员修改尝试拒绝+计数，超 10 次自动拉黑（阈值固定）。
- **拟人防风控机制**：随机延迟、限频、单轮最多 2 条消息（1 文字 + 1 表情包）、安静时段只回不主动——机制内置不可绕过（参数可配）。
- **遗忘曲线**：重要级 ≥4 的记忆永不清理；强情绪记忆衰减更慢（半衰期可配、曲线形状固定）。
- **反思机制阈值**：新记忆 ≥8 条、或 ≥3 条且长期未反思时触发洞察合成；宁少而准。
- **记忆冲突消解**：矛盾事实以 `supersedes` 链取代旧记忆，旧记忆保留可追溯、默认不出现。
- **账号关联流程**：6 位确认码、15 分钟内有效（时长可配）、发起方不能自我确认、冲突由本人选 a/b/merge。
- **自动交接流程**：阈值触发 → 总结 → 存接力笔记 → 换页；管理员可远程发"交接"。
- **LLM 退避算法**：连续失败按 5s×2ⁿ 指数退避（封顶可配），退避期消息保留待补、恢复后续答。
- **NapCat 恢复链**：探测 → 自动发现/拉起 → WebUI hash 认证（sha256(token+".napcat")）→ SetQuickLogin → 人工降级提醒。
- **账密托管加密**：Windows DPAPI，仅本机本用户可解密。
- **表情包自动收集**：每轮最多 3 张、同 URL 去重。
- **本地 WebUI**：仅绑定 127.0.0.1，带令牌鉴权。
- **记录保留**：收发记录永久保留，支持关键词/联系人/时间范围追溯与 Markdown 导出。
