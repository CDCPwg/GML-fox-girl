# 功能清单

> 心跳轮询已移除（看门 + 独立大脑足以覆盖其职责）。消息处理仅两种模式（二选一，互斥）：
> **事件驱动看门** `python server/inbox_watch.py`（消息到达即醒，零模型成本）／
> **独立大脑** `python server/persona_mcp.py --brain`（秒级轮询 + 规则预筛 + LLM 人格回复）。
>
> 本清单按「**要不要用户输入**」划分：功能要跑起来或要改行为时，是必须由用户提供参数/数据/指令，
> 还是程序自己采集数据自主调控。所有配置修改仅限管理员（`admin.qq` / `admin.wechat`）。

## 一、需要用户输入参数或数据来调控

### 1.1 必须提供数据才能工作的功能（不给就不启动/不生效）

| 功能 | 用户需要提供 |
|---|---|
| QQ 渠道 | 安装 NapCat、扫码登录专用小号；可选提供 WebUI 地址与 token（掉线自动快速登录）、托管账密（DPAPI 加密）、NapCat 框架路径（不填则自动发现） |
| 微信渠道 | ADB 连接模拟器/USB 真机、安装中文输入法（ADBKeyboard）、表情包面板坐标校准 |
| 独立大脑（LLM 人格回复/实时沉淀/主动搭话） | OpenAI 兼容 API 地址、密钥、模型名（`brain.api_base/api_key/model`） |
| 语义向量记忆 | embedding 服务地址、密钥、模型（`memory.embed_*`；不提供则退化为关键词检索） |
| 管理体系 | 管理员 QQ 号/微信号名单（`admin.qq` / `admin.wechat`；不配置则聊天内一切指令被拒） |
| 人格内容 | 新建人格（问答式生成）或导入人设卡/SillyTavern 卡（.json/.png）；GLM娘仅是预置初始项 |
| 本地 WebUI 控制台 | 启动命令带 `--token <令牌>`（仅本机 127.0.0.1） |
| 视频抽帧 | 本机安装 ffmpeg（路径可用 `video.ffmpeg_path` 指定） |
| NapCat 自动拉起的密码兜底 | 托管账密（`save_qq_credentials`，用户敏感数据，永不回显） |

### 1.2 由用户指令/参数调控的行为（程序不擅自决定）

- **黑白名单**：用户说"把 xx 拉黑"/"只允许 xx 聊"（联系人/群/全局三种粒度）。
- **人格切换**：工作台 `/persona-switch` 或聊天内管理员指令；聊天侧只能切换不能改内容（锁定）。
- **心情温度**：`manage_mood` 设定 -2~2（需 reason）；影响语气与主动意愿。
- **记忆清理**：`prune_memory` 由管理员发起（先 dry_run 预览，带 keep_score 参数）。
- **账号关联**：需双方用户操作——发起 → 私下转达 6 位确认码 → 对方发"关联确认"；冲突时本人选保留/融合。
- **知情开启开关**（默认关闭，绝不代开）：主动聊天 `proactive.enabled`、即时告警 `alerts.enabled`、自动重开 `limits.auto_reopen`。
- **手动"交接"/"检查消息"**：用户口令触发；自动交接阈值（`limits.warn_pct/handover_pct/auto_handover_turns`）也是用户可调参数。
- **值班表（含自动换班，默认关）**：不设置则全天由大脑或看门二选一处理消息；用户说"开启值班表"时先确认时间节点，再设 `brain.duty_windows`（多段 "HH:MM-HH:MM"，支持跨午夜，段数不限），设置后大脑与看门按时间点自动换班（换班内置于此功能，不单设开关）；关闭说"关闭值班表"。兼容旧键 `duty_start_hour/duty_end_hour`（视为单段）。
- **额度与节奏调参**：回复延迟区间、每小时限频、每日主动上限、群聊回复概率、下载上限、退避封顶、补发队列 TTL、看门重挂超时（环境变量）——日常有默认值，调控时由用户输入。

## 二、程序自己获取数据来调控（无需用户喂，自动运转）

- **看门与收集**：看门只读 SQLite 自己发现待处理消息；collector 自己接收 NapCat 上报（含 chunked 兼容、端口占用自动复用单例）。
- **值班表换班（启用后）**：大脑与看门读同一份值班表配置 + 系统时钟，按时间点自动换班；未启用值班表则双方全天在岗。
- **换班边界防重**：边界前后的消息不无视——大脑发送前自动复查消息处理状态，未被回复的照常回复，已被回复的自动撤销本次回复，绝不双答。
- **实时沉淀**：每条回复成功后大脑自己调 LLM 提取——事实记忆、印象增量、好感、记忆图三元组，宁缺毋滥。
- **主动搭话的对象与话题**：自己查画像（affinity>0）、相关记忆、记忆图、心情、最近对话来选人和开场；额度与安静时段自动门控，没话头自动 [SKIP]。
- **群聊回复必要性**：自己判断被 @/被点名/上轮话题延续/概率门控，广告刷屏自动不回。
- **遗忘曲线**：按重要级、情绪效价、半衰期自动衰减；重要级 ≥4 永不清理。
- **反思机制**：自己攒记忆（≥8 条或 ≥3 条且长期未反思）触发洞察合成，写回画像。
- **记忆冲突消解**：新事实入库前自动查矛盾，矛盾自动以 supersedes 链取代旧记忆，旧记忆保留可追溯。
- **表情包自动收集**：自己下载群里的新表情包、识别情绪打标入库，同 URL 去重，每轮限 3 张。
- **NapCat 掉线自动恢复**：自己探测（OneBot→WebUI 分辨宕机/掉线）→ 自动发现/拉起 → hash 认证快速登录 → 失败才降级提醒人工。
- **发送队列补发**：掉线期间发送自动入队，恢复后自动补发，过期自动丢弃。
- **LLM 退避**：自己计数连续失败，5s×2ⁿ 指数退避，恢复后自动续答并清零。
- **内容防火墙**：collector 层自动拦截损伤本机/骗取信息的入站内容（原文永不进大脑），自动警告计数。
- **出站泄密反向扫描**：发送文本自动比对已托管密钥值，命中即拦。
- **管理守卫**：非管理员修改尝试自动拒绝+计数，超 10 次自动拉黑。
- **人格内容锁定**：聊天渠道的内容修改自动拒绝（origin=chat），机制自动执行。
- **拟人防风控**：随机延迟、限频、单轮 ≤2 条消息（1 文字+1 表情包）——发送工具内自动执行，不可绕过。
- **自动交接**：自己按轮数折算上下文占用，到阈值自动总结→存接力笔记→提醒换页；SessionStart hook 自动归零计数。
- **心情自主漂移**：随互动由大脑自动更新，影响说话温度与主动意愿（用户也可手动设定）。
- **记录与统计**：收发记录自动落库永久保留；统计报表（7 天收发/回复率/好感 TOP 等）自动生成。
- **NapCat 自动发现**：扫运行中 QQ 进程、注册表、常见根目录，自动定位框架目录。
