# glm-foxgirl · GLM狐狸娘（QQ/微信人格伴侣）

让 ZCode 作为"大脑"，以自定义人格在 QQ 和微信里与真人互动：**配置页/聊天区分工**（首次对话只做设置，聊天另起新页）、**自动交接**（上下文约 95% 自动提醒交接换新页，记忆外置无损）、**QQ/微信远程交接指令**、**管理守卫名单**（配置修改仅限管理员，超 10 次尝试自动拉黑）、记录检索与导出、被动回复（定时心跳，默认关闭知情开启）+ 主动聊天、无障碍读屏精确识别每个发言人（通知补捞）、识别图片/表情包/视频（抽帧）、长期记忆（语义检索 + 遗忘曲线 + 情绪效价 + 记忆图）与关系画像、心情状态层、黑白名单权限、拟人化防风控（含 ADB 轨迹随机化）、**人格库热切换**、SillyTavern 角色卡导入、**QQ/WX 账号关联器**（两侧验证码确认，画像继承/合并/冲突自选，记忆按身份组互联）、**反思机制**（定期把记忆合成高层洞察写回画像）、**记忆冲突消解**（新事实自动取代旧事实，保留可追溯）、**NapCat 掉线自动恢复**（登录状态探测 + WebUI 快速登录 + 可选的 DPAPI 加密账密托管）、**内容防火墙**（损伤本机/骗取本机信息的入站内容直接拦截并警告计数，出站泄密反向扫描）、**人格内容锁定**（聊天渠道只可切换表内人格，内容修改仅限工作台）、表情包自动收集、戳一戳、发送队列掉线补发、本地 WebUI 控制台。

## 设计原则

- **独立人格**：狐狸娘是拥有独立人格的"人"，不是群 AI 玩具——刻意不做签到、词云、点歌类娱乐化群功能。
- **记忆外置**：人格/记忆/画像全部在外部 SQLite，换对话页、换设备、备份恢复都无损。
- **知情开启**：一切会定时/主动调用模型的能力（心跳、主动聊天、语义记忆、自动重开）默认关闭，由用户知情开启。
- **内容防火墙**：损伤本机或骗取本机信息/凭据的入站内容在 collector 层直接拦截（永不进入大脑上下文）并发警告计数；出站文本反向扫描已托管密钥防泄密；本机信息与本机操作仅限管理员。
- **人格内容锁定**：聊天渠道只可切换人格表中现有人格；人格内容（性格文本/增删）仅工作台可改，回复性格永远以人格表为准。
- **拟人即安全**：随机延迟、限频、安静时段内置在发送工具里，不可绕过。

## 架构

```
                 ┌──────────────────────────── ZCode（大脑）────────────────────────────┐
                 │  persona-brain 技能：回复必要性 → 人格生成 → 拟人发送 → 记忆沉淀        │
                 └───────────────▲──────────────────────────────────┬───────────────────┘
                                 │ MCP 工具                          │
                   persona_mcp.py（纯 Python 标准库，MCP 服务器 + 事件收集器）
                   存储：~/.persona-bot/  persona.db（SQLite）+ config.json + media/
                     │                                    │
        QQ：NapCat(OneBot11)                     微信：ADB（模拟器/USB 真机）
        HTTP 上报 → collector → SQLite            截图识图 + ADBKeyboard 发送
```

## 数据与备份

全部外部存储在 `~/.persona-bot/`（可用环境变量 `PERSONA_BOT_DATA_DIR` 改）：`persona.db`（人格/记忆/画像/黑白名单/表情包/消息日志）、`config.json`（渠道与行为配置）、`media/`。**备份这个文件夹即备份一切。**

## 快速开始

1. 安装后的第一次对话是**配置页**：自动列出全部可修改功能（SessionStart 速览），在这里完成渠道接入（"接入QQ/接入微信"）、人格（GLM娘已预置）、管理员与知情开启项（心跳/主动聊天/语义记忆）。
2. 配好后说"**完成配置**"（/persona-finish-setup）：校验关键项并封存配置页。
3. **新开一个对话作为聊天区**：开机自动恢复值机（接力笔记；把仓库 workspace/ 设为工作区、AGENTS.md 生效效果最佳）。日常聊天、看消息都在聊天区。
4. 聊天区上下文占用按轮数折算估算：约 85% 轻提醒、约 95% **自动交接**（`limits.warn_pct`/`handover_pct` 可改；`limits.auto_reopen=true` 知情开启后交接时自动建恢复页定时任务）。管理员在 QQ/微信里发"**交接**"即可远程换页；**管理守卫**：所有配置修改仅限管理员名单，其他账号尝试会被警告，单账号超 10 次自动拉黑不再回复。记录随时 `search_messages` / `export_transcript` / WebUI 追溯。
5. 消息心跳（定时自动收发）**默认关闭**：需要时在聊天区说"开启15分钟心跳"，"关闭心跳"即停。
