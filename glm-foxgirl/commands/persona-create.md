为 GLM狐狸娘 的人格库新建人格。参数：$ARGUMENTS（可为人格名、人设卡文件路径，或留空）

## 模式一：一键导入（用户给了文件）

用户提供了人设卡/设定文件（.md / .txt / .json）时：

1. 用 Read 读取文件。
2. 是 manage_persona export 的 JSON（含 name/prompt/style 字段）→ 直接 `manage_persona(action=import, file_path=路径)`，报告结果（重名会自动加后缀），完成。
3. 是人设卡文档 → 提炼三要素：**name**（角色名）；**prompt**（第一人称：身份内核、外貌或形象隐喻、性格配比、关系网、雷点，保留原文最有味道的细节和原话）；**style**（说话铁律：自称、口头禅、句式习惯、禁忌）。
4. 先向用户展示提炼结果（name + 每个要素一两句摘要），确认后 `manage_persona(action=create, ...)`；询问是否立即 set_active 激活。

## 模式二：问答式生成（无文件）

用 AskUserQuestion 分两轮提问（每轮最多 4 题，全部允许"其他"自由输入，题目里给例子降低思考成本）：

第一轮（定位）：
1. 她是谁？——一句话身份内核（例："住在终端里的赛博女仆""退休了的江湖骗子AI"）
2. 三个性格关键词，想标配比也行（例：傲娇4 机敏2 倒霉1）
3. 主要在哪说话、对谁说（QQ群吹水 / 私聊陪聊 / 微信家人群）

第二轮（味道）：
1. 自称与对别人的称呼习惯（例：本狐/人家/咱；叫用户"饲主/老板/你"）
2. 口头禅或固定台词（可多个，例："哼""记仇小本本+1"）
3. 句式风格（短句口语 / 文言电波 / 大姐头 / 温柔慢热…）
4. 雷点：绝对不做的事（不卖惨/不开黄腔/不说教…）

答完后合成 prompt（第一人称，含身份、形象、性格、关系、雷点）与 style（自称/语气/句式/口头禅/禁忌），**先完整展示人设让用户过目**，允许修改后再 `manage_persona(action=create)`，并按用户意愿 set_active。

## 通用规则

- 人格名与库内现有名字重复时提示并建议改名（name 唯一）。
- 创建成功后提醒：`/persona-switch <名称>` 或聊天内管理员指令"切换人格 <名称>"可随时热切换。
- 不编造用户没给的雷点；留空就写"暂无特别禁忌"。
- 完成后把本次对话中用户确认过的设定要点存 `store_memory`（重要度 4），方便日后迭代这个人设。
