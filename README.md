# 🦊 GLM狐狸娘 · QQ/WeChat 人格伴侣

**让 ZCode 作为"大脑"，以一个有独立人格、有长期记忆、会主动社交的狐狸娘身份，在 QQ 和微信里与真人互动。**

这不是一个"聊天机器人框架"，而是一套围绕**人格连续性**设计的完整系统：她记得你说过的话（并会遗忘该遗忘的）、对每个人都有独立的印象与好感、定期"反思"你们的关系、被冒犯会记仇、上下文满了会自己交接记忆换个"脑子"继续陪你聊。

> 设计哲学：**她是一个拥有独立人格的"人"，不是群聊玩具**——刻意不做签到、词云、点歌这类娱乐化群功能。

---

## ✨ 功能全景

### 🧠 人格与记忆（核心）
- **人格库**：多人格存储，热切换（工作台指令 / QQ·微信内管理员指令），GLM娘 预置为初始人设
- **人设获取**：问答式生成 `/persona-create`、人设卡文件一键导入、**SillyTavern 角色卡**（.json/.png）导入
- **长期记忆**：重要级分级 + 情绪效价 + 遗忘曲线（强情绪记忆衰减更慢）+ 语义向量检索（可选）
- **记忆图**：人物-事件-偏好关联网络，聊到"煤球"能联想到"阿明"再到"王者荣耀"
- **反思机制**：新记忆攒够后自动把碎片记忆合成高层洞察，写回画像——"越聊越懂你"
- **记忆冲突消解**：新事实自动取代旧事实（"换游戏了"会覆盖"在玩XX"），旧记忆保留可追溯
- **关系画像**：每个联系人独立印象档案 + 好感度（-100~100），跨平台身份互联后共享

### 📡 双渠道接入
- **QQ**：NapCat（OneBot 11）协议端，电脑运行无需手机，收发文字/图片/表情包、群名片级发言人识别、戳一戳
- **微信**：ADB 控制模拟器或 USB 真机——无障碍读屏精确识别每个发言人（含群昵称）、截图视觉识图、通知栏补捞错过的消息、ADBKeyboard 发送
- **双车道与跨端接续**：QQ/微信作为两条独立车道处理，上下文互不掺和；账号关联后换端，另一端的往来自动并入对话上下文（微信发送默认读屏守卫防串台）

### ⚡ 实时性（三层）
| 层 | 延迟 | 模型消耗 |
|---|---|---|
| 消息接收入库 | 毫秒 | 零 |
| 即时系统告警（防火墙拦截/掉线恢复，直发管理员） | 秒级 | 零（罐装文本） |
| 人格回复 | **独立大脑守护进程：秒级** / 事件驱动看门（消息到达即醒） | LLM 按需调用 |

- **独立大脑守护进程**（可选）：秒级轮询收件箱，会话分组并发（多人同时回复不掉线，同一人连发合并回应），规则预筛（黑白名单/管理指令/群聊必要性判定零成本执行），仅对需要人格的消息调用 LLM（OpenAI 兼容 API）
- **NapCat 掉线自动恢复**：登录状态探测 + 自动发现并拉起 NapCat + WebUI 快速登录 + 可选的 DPAPI 加密账密托管

### 🗣️ 多模态
图片/表情包识别与回应、表情包库自动收集（按情绪打标、URL 去重）、视频抽帧理解（ffmpeg）、语音消息识别（规划中）

### 🔄 会话连续性
- **配置页 / 聊天区分工**：首次对话只做配置，聊天另起新页
- **自动交接**：上下文约 85% 轻提醒、约 95% 自动总结存档换新页（阈值可调），记忆外置换页无损
- **接力笔记**：新对话开机自动恢复值机；随时手动"交接"
- **记录追溯**：收发记录永久保留，关键词/联系人/时间范围检索，导出 Markdown 存档

### 🛡️ 安全模型
- **知情开启**：一切定时/主动调用模型的能力（主动聊天、语义记忆、实时大脑、自动重开）默认关闭
- **内容防火墙**：损伤本机或骗取本机信息/凭据的入站内容在 collector 层直接拦截（**永不进入大脑上下文**），警告并计数，超限自动拉黑；出站文本反向扫描已托管密钥防泄密
- **管理守卫**：配置修改仅限管理员名单；非管理员尝试被警告，超 10 次自动拉黑
- **人格内容锁定**：聊天渠道只可切换人格表中现有人格；人格内容仅工作台可改
- **拟人防风控**：随机延迟、每小时限频、安静时段、ADB 轨迹随机化，内置不可绕过
- **本机信息与操作仅限管理员**

### 🖥️ 本地 WebUI 控制台
状态总览、人格在线编辑与激活、记忆/画像/黑白名单/表情包管理、聊天记录搜索、接力笔记、统计报表（仅绑定 127.0.0.1）

## 🏗️ 架构

```
              ┌────────────────────────── 大脑层（二选一/可组合）──────────────────────────┐
              │  ZCode 会话（persona-brain 技能驱动）      独立大脑守护进程（--brain，可选）  │
              │  事件驱动看门（消息到达即醒）              秒级轮询 + 规则预筛 + LLM API     │
              └──────────────▲──────────────────────────────────▲──────────────────────┘
                             │ MCP 工具（47 个）                  │
                persona_mcp.py（纯 Python 标准库，按领域模块化：foxbot/ 包）
                存储：~/.persona-bot/  persona.db（SQLite）+ config.json + media/ + transcripts/
                  │                                      │
     QQ：NapCat(OneBot11)                     微信：ADB（模拟器/USB 真机）
     HTTP 上报 → collector(兼容chunked) → 库   无障碍读屏 + 截图视觉 + ADBKeyboard
```

**47 个 MCP 工具**覆盖：人格库、记忆（含冲突消解/反思）、记忆图、关系画像、账号关联、黑白名单、双渠道收发、表情包、统计、会话接力、登录托管、内容防火墙审查……

## 🚀 快速开始

1. **获取代码**：`git clone` 本仓库（或 Download ZIP 解压）
2. **安装插件**：ZCode → 插件市场 → 添加 → 添加插件市场 → 选择**本仓库根目录**（内含 `marketplace.json`）→ 个人 → 安装「GLM狐狸娘」
3. **配置页**：安装后第一次对话自动展示分步功能指南——接入渠道（"接入QQ"/"接入微信"）→ 人格（GLM娘已预置）→ 管理员 → 可选知情开启项
4. **完成配置**：说"完成配置"封存配置页
5. **聊天区**：新开一个对话作为日常聊天区，开机自动恢复值机；QQ 里跟她说句话试试
6. **进阶**：实时大脑（提供 LLM API）、语义记忆（提供 embedding API）、即时告警、账密托管——都在配置页指南里

> 详细接入教程见 [`glm-foxgirl/skills/`](glm-foxgirl/skills/)（qq-napcat-setup / wechat-adb-setup），日常操作手册见 [`glm-foxgirl/skills/persona-brain/SKILL.md`](glm-foxgirl/skills/persona-brain/SKILL.md)。

## 📦 数据与备份

全部状态外置在 `~/.persona-bot/`（可用环境变量 `PERSONA_BOT_DATA_DIR` 重定向）：`persona.db`（人格/记忆/画像/黑白名单/表情包/消息日志/接力笔记）+ `config.json`（渠道与行为配置，密码经 Windows DPAPI 加密）+ `media/` + `transcripts/`。

**备份该目录即备份一切。** 换电脑、重装、换对话页，人格与记忆都在。
